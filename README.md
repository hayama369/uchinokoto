# うちのこと

家族の予定、やること、買い物、ほしいもの、ハルのお世話を一か所で見る、静かな家庭用ダッシュボード。
この家には黒猫のハルが住んでいる。ハルは催促しない。

## いまできること（Phase 1）

| タブ | 中身 |
|---|---|
| 今日 | 日付、夫の状態（休みの日だけ）、次の夫の休み（あと何日・何連休）、今日の予定、今日のやること、買い物、ハルのお世話 |
| カレンダー | 月表示。1日2件まで＋「ほか○件」。レイヤー（自分／夫／家族／家／ハル／夫の休み）の表示切り替え。日付を押すと詳細 |
| リスト | やること（今日／今週／いつか）、買い物（よく買うものから再追加）、ほしいもの（画像・価格・URLなど）、やりたいこと（叶ったら履歴に残る） |
| ハル | お世話の「やった」ボタン、最後にやった日、最近14日の記録。項目は編集できる |
| うち | 家族の名前、この端末は誰か、夫の休みの登録、合言葉 |

- 右下の「＋」は、どの画面からでも押せる。入力必須は名前だけ
- 「やった」「買った」「済んだ」は、どれも数秒以内なら取り消せる
- 記録しない日があっても壊れない。記録は義務じゃない

### ハル

画面の一番下、タブの上にある「床」がハルの通り道。ボタンはそこに置いていないから、ハルが何かを隠すことはない。

- ふだん：ゆっくり歩いて、ときどき座る
- 買い物：袋をのぞく
- ハル画面：ごはん皿のそば
- ほしいもの・やりたいこと：座って見上げる
- 今日の画面で、今日のやること・「毎日」のお世話・この後の予定が全部済んだ：丸くなって寝る

さわると鳴く。動きを減らす設定の端末では歩かない。

## 合言葉の準備（最初に1回だけ）

家族と共有するには、Vercel に「データの置き場所」を1つ足す必要がある。
（足さなくても、端末ひとつで普通に使える）

1. Vercel でこのアプリのプロジェクトを開く
2. 「Storage」タブ（または Marketplace）から **Upstash の Redis** を選んで作成する（無料プランでいい）
3. 作るときに、このプロジェクトに「Connect（接続）」する
   → 接続情報（`KV_REST_API_URL` と `KV_REST_API_TOKEN`）が自動で入る
4. 「Deployments」から最新のものを **Redeploy**（もう一度公開）する
5. アプリの「うち」→「新しく合言葉を作る」
6. 夫のスマホでアプリを開き、「うち」で「この端末を使うのは：夫」を選んでから、合言葉を「つなぐ」に入れる

※ Vercel の画面は時々変わるので、ボタンの名前が違ったらスクショを見せて。
※ 任意：環境変数 `SYNC_PEPPER` に好きな長い文字を入れておくと、合言葉がさらに推測されにくくなる
（入れたら、もう変えないこと。変えると別の家になる）

### 合言葉のしくみ

- 合言葉はサーバーにそのまま保存しない。暗号化した値を「家の置き場所の名前」に使うだけ
- 合言葉を知っている人は、誰でも中身を見られる。家族以外には教えない
- 同じものを2人で同時に変えたら、後から変えたほうが残る
- オフラインでも記録はできる。つながったときにまとめて送る
- 「この端末の共有をやめる」を押しても、この端末のデータは消えない

## データの置き場所

- 各端末のブラウザの中（IndexedDB）に保存
- 合言葉でつないでいるときは、Upstash Redis にもコピーがある
- iPhone では **必ず「ホーム画面に追加」して使う**（Safari は、ホーム画面に追加していないサイトのデータを、しばらく使わないと消すことがある）

## ファイルの役割

| ファイル | 担当 |
|---|---|
| `index.html` | 画面の枠（タブ・ハルの通り道・＋・シート） |
| `style.css` | 見た目。色は一番上にまとめてある |
| `js/util.js` | 日付の計算、画面部品を作る小道具 |
| `js/store.js` | データ係。保存・読み込み・変更の通知（クラウドに移すときはここと sync.js を差し替え） |
| `js/sync.js` | 合言葉での同期係 |
| `js/model.js` | 「次の休み」「今日のやること」「最後にやった日」などの読み方 |
| `js/haru.js` | ハルの形と、場面ごとの過ごし方 |
| `js/sheet.js` | 下から出るシート（PCは右）とお知らせ |
| `js/ui.js` | よく使う部品（カード・チップ・チェック） |
| `js/forms.js` | 追加・編集の入力欄と「＋」。項目を足すならここの TYPES |
| `js/views/*.js` | 各タブの画面（today / calendar / lists / care / home） |
| `js/app.js` | 起動、タブの切り替え、描き直し |
| `api/sync.js` | Vercel 上で動く同期の受け口（Upstash Redis に保存） |

## データ構造

すべての記録に `id, createdAt, updatedAt, deleted` が付く（削除は「消した」印を付けて残す。相手の端末に削除を伝えるため）。

```
settings  (id:'family')  people: { me:{name}, partner:{name} }
events      title, date('2026-10-03'), time('11:30'|null), owner(me|partner|family|house|haru), note
workdays    id:'partner:2026-10-05', personId, date, type('off'|'work'), source('manual'|'csv'|'ics'|'pdf')
tasks       title, bucket(today|week|someday), assignee(me|partner|either|null), dueDate, completedAt, completedBy
shopping    title, completedAt（買った日時）, purchasedBy
wishes      title, image(縮小した画像), price, url, owner, priority(high|mid|low), note, purchasedAt
dreams      title, category(go|eat|see|family|make), note, completedAt（叶った日）
careItems   title, everyDays(1=毎日の目安 / null), order  ※初期項目：ごはん・水の交換・給水機の手入れ・フィルター交換・トイレ掃除・遊ぶ・猫砂全交換・ブラッシング・爪切り・通院・薬
careLogs    careItemId, performedBy, performedAt
```

- **勤務（workdays）は予定（events）と別**。来年の勤務表に差し替えるときは、`source` と期間で消して入れ直す
- 端末ごとの設定（この端末は誰か・表示レイヤー・合言葉）は localStorage

## 公開のしかた

フォルダの中身を GitHub に置いて Vercel にデプロイ（ビルド設定は不要）。`api/sync.js` は自動で `/api/sync` になる。
